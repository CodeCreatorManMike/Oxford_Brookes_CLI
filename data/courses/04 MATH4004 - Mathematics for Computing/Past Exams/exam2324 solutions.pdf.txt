6. (a) A palindrome is a string of digits that reads the same backwards as it reads
forwards. For example
123454321
is a palindrome. How many different palindromes are there with 9 digits,
assuming that palindromes cannot start with a zero?
2 marks
The first five digits can be chosen, whereas the final four are fixed (so that
the string is a palindrome). The first digit cannot be zero and so can be any
of the digits 1–9, i.e. there are 9 possibilities for the first digit. The
remaining four digits can be any of the digits 0–9, i.e there are 10
possibilities for these digits. Hence, the number of palindromes is
4
9×10 = 90000.
[2 marks]
