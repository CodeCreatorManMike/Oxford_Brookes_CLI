4 Relations
Properties of binary relations
A binary relation between sets A and B is a subset R of A×B.
If A = B, then R is called a relation on A.
A relation R on a set A is:
• reflexive when xRx for all x in A;
• symmetric when xRy ⇒ yRx for all x and y in A;
• antisymmetric when xRy and yRx ⇒ x = y for all x and y in A;
• transitive when xRy and yRz ⇒ xRz for all x, y, and z in A.
Equivalence relations
A relation R on a set A which is reflexive, symmetric, and transitive is called an
equivalence relation. The equivalence class of x ∈ A is the set
E = {z ∈ A : zRx}.
x
Distinct equivalences classes have no elements in common and their union forms a
partition of the set A.
Partial orders
A relation R on a set A which is reflexive, antisymmetric, and transitive is called a
partial order. Sets on which a partial order is defined are called posets. A total
ordering on a set is a partial order in which every pair of elements are related.
If R is a partial order on a set A and xRy, x ̸= y, then x is called a predecessor of y.
If x is a predecessor of y and there is no z for which xRz and zRy, then x is called an
immediate predecessor of y. Immediate predecesssors can be represented on a
graph known as a Hasse diagram.

6 Graphs
Basic terminology
An Eulerian cycle is a cycle in a graph that passes through each edge exactly once.
A graph containing such cycle is called an Eulerian graph. A connected graph with at
least two vertices is Eulerian if and only if there are no vertices of odd degree.
The handshaking lemma: In any graph, the sum of all the vertex degrees equals
twice the number of edges.
A simple graph is a pair G = (V,E) whereV is a finite set of vertices and E is a
finite set of edges such that G contains no loops and no multiple edges.
The matrix representing the edge relation E of a simple graph is called the adjacency
matrix of G.
′ ′ ′ ′ ′
A subgraph of a graph G=(V,E) is a graph G =(V ,E ) with E ⊆E andV ⊆V.
Connectivity
A connected graph is one in which there exists a path between every pair of vertices
in the graph. The number of connected components in a graph can be determined by
using the connectivity algorithm.
Hamiltonian cycles
A Hamiltonian cycle is a cycle in a graph that passes through each vertex exactly
once. A graph containing such a cycle is called a Hamiltonian graph.
The travelling salesperson problem is to find a Hamiltonian cycle of minimal total
weight in a weighted graph. The nearest neighbour algorithm may be used to find a
suboptimal solution to the travelling salesperson problem.

Trees
A graph is a tree if it is connected and acyclic.
The following statements about a graph G = (V,E) with n vertices and m edges are
equivalent:
1. G is a tree.
2. There is exactly one path between any two vertices of G.
3. G is connected and m = n−1.
4. G is connected and the removal of a single edge disconnects G.
5. G is acyclic and adding a new edge creates a cycle.
A spanning tree for a graph G is a tree constructed from the edges of G which
includes all the vertices of G.
The minimum connector problem is to find a spanning tree for a graph with
weighted edges of minimal total weight. The minimal spanning tree algorithm
produces a spanning tree of minimal total weight in a weighted graph.
A rooted tree is a tree in which one vertex is distinguished and called the root of the
tree. Vertices immediately below a vertex v are called the children of v.
Each vertex in a rooted tree T forms the root of another rooted tree called a subtree
of T. In a binary rooted tree each vertex has at most two children and the two
subtrees of a vertex v are called the left-subtree and the right-subtree of v.
A binary search tree is a binary rooted tree in which each data item in the
left-subtree of any vertex v is less than the data item stored at v and each data item in
the right-subtree of any vertex v is greater than the data item stored at v.
The search algorithm can be used to search for particular data items in a binary
search tree and the insert algorithm can be used to insert new data.

7 Digraphs
Consistent labelling
In task-scheduling problems, an acyclic digraph is called a PERT chart.
A consistent labelling of an acyclic digraph G = (V,E) is a labelling 1,2,··· ,n of
the vertices such that if uv is an arc and u has label i and v has label j, then i < j.
A digraph has a consistent labelling if and only if it is acyclic. The topological sort
algorithm produces a consistent labelling of an acyclic digraph.

Elementary row operations
There are three types of elementary row operation that can be applied to a matrix:
1. Adding a multiple of one row to another row.
2. Multiplying a row by a non-zero number.
3. Swapping the entirety one row with another row.
If two matrices can be obtained from one another using some sequence of
elementary row operations, then the two matrices are said to be row equivalent.
Gaussian elimination
The first non-zero number of some row in a matrix is called the leading coefficient
(or sometimes pivot) of that row.
A matrix is in row-echelon form if
1. all rows that are entirely zeros are grouped together at the bottom of the matrix;
2. in any two consecutive rows that are not entirely zero the leading coefficient of
the lower row occurs to the right of the leading coefficient in the higher row.
The matrix is said to be in reduced row-echelon form if in addition
1. the leading coefficient of any non-zero row is 1;
2. any column that contains a leading 1 has zeroes everywhere else.
