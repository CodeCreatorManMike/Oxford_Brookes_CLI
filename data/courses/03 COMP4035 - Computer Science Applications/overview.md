### Timetable Requests
The number of students allocated to each practical is at capacity so there isn't much room to make changes to practical classes, but there is a central system where requests to change set can be made.

Timetabling info: https://www.brookes.ac.uk/students/timetabling
- "Timetable Support" link -> ServiceNow page called Timetable Support. Second line has the link to submit a Set Change Request.
- Personal timetable access is also available through that link.
- For all COMP4035 practical times: use the link, click "Module timetables" yellow box, search "COMP4035".
- Troubleshooting: ServiceNow is a separate Brookes system - if taken to a login page, log in with normal username/password, keep that tab open, then reopen the timetabling page in another tab.
