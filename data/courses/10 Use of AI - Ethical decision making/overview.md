## Introduction
AI tools are widely used in Higher Education. Course helps make ethical decisions using AI for learning/assessment - understand appropriate vs inappropriate use in assignments, aligned with university regulations.

Appropriate use = upskilling (you learn/develop by using the tool). Inappropriate use = downskilling (you don't learn/develop, may lose ability). "At risk" = middle ground that could lead to inappropriate use - check with tutor/module guide before proceeding.

Traffic lights: Green (GO) = appropriate, Amber (CHECK) = at risk, Red (STOP) = inappropriate.

## Traffic Light Table (by theme)

**Authorship**
- Appropriate: Ethical use where you are still the author of the assignment
- At risk: Relying on AI tools for a part of the assignment
- Inappropriate: Unethical use where you are no longer the author of the assignment

**Transparency**
- Appropriate: Transparent use - make clear where/how AI was used
- At risk: Using AI but not acknowledging all use
- Inappropriate: Deceptive use - using AI without acknowledging it

**Reading and referencing**
- Appropriate: Using AI tools to search for appropriate academic literature
- At risk: Using AI to generate summaries of articles instead of reading them
- Inappropriate: Asking AI to generate references instead of doing research/reading

**Starting assignments**
- Appropriate: Helping get started with ideas
- At risk: Using AI to generate a part of the assignment
- Inappropriate: Putting the whole assignment task into AI and using output with little/no changes

**Developing assignments**
- Appropriate: Small changes e.g. correcting spelling
- At risk: Using AI for a lot of the development of an assignment
- Inappropriate: Asking AI to write the arguments and conclusion for an assignment

**Completing assignments**
- Appropriate: Proofreading/checking before submission
- At risk: Using AI to re-write an assignment at the final stage
- Inappropriate: Using AI tools to answer exam questions

**Following assessment instructions**
- Appropriate: Using AI tools with instruction/guidance from the tutor
- At risk: Using AI in ways the tutor has not recommended
- Inappropriate: Using AI when assignment instructions state AI must not be used

Note: For "at risk" practice, always check with tutor or assignment instructions.
